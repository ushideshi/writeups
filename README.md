# Writeups

This is a list of writeups I wrote over time for different vulnerable machines.  I've written then up for studying purpose in order to practice, hack katas in some way, and as a mean to take notes of the direction I chose for each of them.

As Miyamoto Musashi once wrote : " There is more than one path to the top of the mountain. " 

Therefore, the path I chose might not be the one you decided to undertake.  That's all right; there are multiple ways to complete a CTF challenge, multiple tools can be used.

I suggest, once you complete a CTF, you should read other write`ups about the same box to see what path others took and try them in order to learn even more along the way.  Be advised that some writeups might not work anymore, that happened to me more than once.

For each Boxes, I provide a link to the VirtualBox image download, so you can try it yourself.  Remember to __never expose a vulnerable box to the internet__.

For those of you who are at their first tries at hacking: do not be intimidated with working in the command line (CLI). Pretty much everything will be done without a GUI, you'll get comfortable eventually.

You could create a Kali linux VM or use an old laptop with Kali installed on it, but if you are already using a debian based linux distro, you can install pretty much every package, like nmap, metasploit, gobuster etc. manually via apt install.
